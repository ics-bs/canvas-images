# Canvas Banner Design Guide

This file records the course-specific design instructions used in the generated prompt files.

Each design instruction is inserted after this base-prompt sentence:

> They should contain a small number of central, attention-grabbing objects:


## bachelors-programme/semester-1-sysa21-blueprint-blue

- Business, IT and Digitalization: a central digital business flow with three large connected forms: an organization block, an IT platform block, and a customer service channel, linked by broad information-flow arrows.
- Information Systems as a Subject: a large socio-technical systems triad with three connected pillars for people, process, and technology surrounding one central information system core.
- Software Development: a central software construction motif with large modular code-free components, a simple control-flow path, and one application frame assembled from clean geometric blocks.
- Systems Analysis and Modelling: a central analysis board with a large process model, a simplified data model, and a magnifying-glass-like inspection frame tying the models together.
- Information Systems Project: a semester-one project synthesis showing one central information system prototype connected to a business process flow, a software module, and a simple analysis model.

## bachelors-programme/semester-2-sysa12-muted-gold

- Organizations, Business and Information Systems: a central enterprise map with large organizational units, an information system platform, and broad data-flow routes connecting business operations to digital support.
- Interaction Design: a central interaction design workspace with two large wireframe screens, a cursor or touch target, and a simple user journey path connecting key interface states.
- Project Management: a central project planning board with milestone blocks, dependency lines, and a simple timeline arc leading toward one clear delivery marker.
- Group Dynamics: a central collaboration model with a few balanced role circles, communication paths, and one shared workspace node showing team coordination without faces.
- IT Law: a central digital compliance motif with a document stack, a lock, and a balanced scale-like geometric form connected to system boundary lines.
- Information Systems Project: a semester-two project synthesis showing a central service concept linked to an organization map, an interface wireframe, a project timeline, and a compliance boundary.

## bachelors-programme/semester-3-sysb23-emerald-green

- Enterprise Architecture: a central enterprise architecture stack with large business, application, data, and technology layers connected by a few vertical alignment lines.

- Responsible Business Development: a central responsible value model with stakeholder nodes, a circular development path, and balanced business, social, and environmental value pillars.
- Information Systems Project: a semester-three project synthesis showing a central enterprise solution connected to a database model, strategy dashboard, process improvement loop, security perimeter, and responsibility markers.
