# Canvas Course Banner Color Outline

## Design rule
For each banner family, use a **single hue family**:
- the **background** should be a **dark muted version of the same color**
- the **shapes / main objects** should use **lighter tones of that same color**
- the **linework** should use **pale technical tints** within the same family
- keep the overall look **restrained, academic, and blueprint-inspired**
