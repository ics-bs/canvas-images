# SYSG16, Applied Project on the Bachelor Programme in Design of Information Systems

## Copy/Paste Prompt

Create two related images for a university Canvas course page, using the same design and visual identity.

Output 1: a 3:1 ultrawide banner illustration.
Output 2: a 1600 × 896 thumbnail version derived from that banner.

First create the banner as the master image. Then create the thumbnail based on the banner you created. The thumbnail must be a version of the same image, not a different redesign. It should preserve the same central objects, style, color palette, composition logic, and overall visual identity, but be adapted to the 1600 × 896 format.

When composing the banner, keep all essential visual elements inside a centered 16:9 safe area so they remain visible and readable in the thumbnail crop. The far left and far right edges of the banner may contain only nonessential background space, grid structure, or subtle construction details.

Use a clean, unified blueprint / schematic visual style with precise linework, elegant geometry, and a restrained technical or drafting feel.

The banner and thumbnail must be simple, bold, and readable at a glance.
They should contain a small number of central, attention-grabbing objects: a capstone delivery scene with one central working system prototype, implementation milestones, stakeholder nodes, and integration paths showing applied design work.
These objects should be the clear focus of both images and should make the design immediately distinguishable from other banners in the same style.

If relevant, include a subtle subject-specific cue, but no readable text.

The image should not look like a dense technical diagram.
The schematic / blueprint language should appear only as the visual style: clean construction lines, subtle connectors, restrained technical framing, and a faint blueprint grid or drafting background.
Do not fill the image with many small parts, excessive labels, dense annotations, busy side panels, or cluttered decorative details.

Prioritize strong visual hierarchy, large recognizable shapes, negative space, and clarity from a distance.
If there is a choice between more detail and a clearer composition, prefer clarity and simplicity.
Use fewer, larger, more memorable elements rather than many small ones.

Use the following color palette: deep violet background, pale lavender technical linework, lighter violet object highlights, restrained monochrome violet blueprint palette.
The image should feel like a restrained academic blueprint, with muted tones, crisp technical linework, subtle illumination, and a quiet background subordinate to the main objects.

Make all main elements feel like they belong to the same visual system, with consistent stroke weight, consistent blueprint rendering, and a balanced composition suitable for both a Canvas banner and a Canvas thumbnail.

Overall feel: coherent, modern, academic, elegant, minimal, restrained, and blueprint-inspired.
